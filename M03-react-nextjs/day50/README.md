## Peer review

Use the partner's application before opening any code. Then follow one feature
end to end and check one protected action for both checks (the interface hides
it, and the server refuses it). Write three specific strengths and three
questions worth answering.

Hakim's REVIEW.md holds a review of Hakim itself. The review of your partner's
project is written on the day.
