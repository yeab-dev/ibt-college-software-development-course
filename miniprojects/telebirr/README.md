# TeleBirr Transaction Report

A small JavaScript program that processes TeleBirr transactions using modern JavaScript features.

## Files

- `transactions.js` — Contains and exports transaction data.
- `report.js` — Contains reusable functions for filtering, totaling, formatting, and updating transactions.
- `app.js` — Imports the data and report functions and prints the final report.

## Concepts Used

- `map`
- `filter`
- `reduce`
- Object destructuring
- Spread syntax
- ES modules
- `Object.entries`
- `for...of`

## Run

```bash
node app.js
