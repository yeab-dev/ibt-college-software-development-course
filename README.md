# IBT College · CodeOps Full Stack Software Development

My coursework for the IBT College CodeOps Full Stack program, organised by module and day.

| Module | Folder | Days | Topics |
|---|---|---|---|
| 1 · Foundation | [M01-foundation](M01-foundation/) | 01–10 | Git & terminal, Python, OOP, design patterns, data structures & algorithms |
| 2 · Web Fundamentals | [M02-web-fundamentals](M02-web-fundamentals/) | 11–25 | HTML, CSS, JavaScript, DOM, async & APIs |
| 3 · Frontend: React & Next.js | [M03-react-nextjs](M03-react-nextjs/) | 26–50 | React, then Next.js — built around the Addis Eats app |

Highlights:

- [Addis Bank](M01-foundation/projects/addis_bank/): a Python banking system (OOP, design patterns, DSA)
- [Mini-projects](M02-web-fundamentals/miniprojects/) and [assignments](M02-web-fundamentals/assignments/) from Module 2
- Addis Eats: a food-ordering app that grows a day at a time. Each `M03-react-nextjs/dayNN/addis-eats` is a snapshot of the app at the end of that day. The latest is [day 42](M03-react-nextjs/day42/addis-eats/).

Each JavaScript project is self-contained: `cd` into its folder, then `npm install` and `npm run dev`.
