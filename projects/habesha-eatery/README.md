# Habesha Eatery

A two-page accessible mini-site for a fictional restaurant in Bole, Addis Ababa.

## Pages

- `index.html` — reservation page with menu table and media block.
- `contact.html` — contact form and opening-hours table.

## How to open

Open `index.html` in a web browser.

The two pages can also be served with a local static server.

## Accessibility features

- Semantic HTML elements such as `nav`, `main`, `section`, `form`, `table`, `figure`, and `address`.
- Descriptive page titles and meta descriptions.
- Proper labels associated with all form controls.
- Native HTML buttons and links for keyboard accessibility.
- Meaningful alternative text for images.
- Table captions and `scope` attributes for headers.
- `aria-current="page"` identifies the current navigation page.
- Navigation links work with the keyboard.
